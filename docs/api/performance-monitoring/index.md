# Performance Monitoring - API Documentation

## Overview

The Performance Monitoring feature tracks network and device traces reported by your apps. API endpoints let you change the alert threshold and the issue status of a trace.

## Quick Links

- [Performance Monitoring - Edit Trace Threshold](i-apm-edit.md)
- [Performance Monitoring - Change Trace Status](i-apm-change-status.md)

## Operational Notes

- Both endpoints apply to traces of type `network` or `device`.
- Each successful change is written to system logs.
